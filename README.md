# Muzaffer Türkoğlu

GitHub profilime hoş geldin. Burada mobil uygulama, gömülü sistem, veri analizi ve web uygulaması projelerimi paylaşıyorum.

## Çalıştığım teknolojiler

- **C# ve .NET MAUI:** Mobil ve masaüstü uygulamaları.
- **C ve STM32 HAL:** Mikrodenetleyici ve GPIO uygulamaları.
- **Python:** Makine öğrenmesi ve ağ optimizasyonu.
- **PHP ve MySQL:** Veritabanı destekli yönetim uygulamaları.
